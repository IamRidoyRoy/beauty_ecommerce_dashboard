# Courier Dashboard Module

Route: `/courier/orders`

The module lists Packed and Shipped orders. Packed rows are selectable; Shipped rows are view-only. Select a courier, choose one or multiple Packed orders, and submit. Successful rows become Shipped and display the submitted courier and tracking code.

Each row includes **Details** (popup modal) and **Invoice** actions. Shipment tracking/history remains available under **Sales → Shipment Tracking**.
