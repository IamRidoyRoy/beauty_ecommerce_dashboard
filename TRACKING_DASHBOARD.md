# BEAUTYOPS Pixel & Tracking

Open **Marketing → Pixel & Tracking**.

The page controls:

- Global tracking on/off
- Browser Pixel channel through Google Tag Manager
- Server channel through Meta Conversions API
- GTM Web Container ID
- Meta Pixel ID
- CAPI access token
- Graph API version
- Test Event Code
- Currency
- Marketing consent requirement
- Per-event switches
- CAPI test request
- Recent server delivery logs

The CAPI token is write-only in the UI. Once saved, the API returns only a masked/configured state.

See `GTM_META_PIXEL_CAPI_SETUP.md` for the required one-time GTM container setup.
