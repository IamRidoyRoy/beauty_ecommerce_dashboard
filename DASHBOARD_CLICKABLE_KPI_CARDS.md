# Clickable dashboard KPI cards

Dashboard KPI cards now act as navigation shortcuts:

- Today's Revenue -> Reports / Sales / Today
- Today's Orders -> Sales / Orders filtered to today's date
- Units Sold -> Product Performance / Today
- New Customers -> Customers
- Average Order Value -> Sales Report / Today
- Gross Profit -> Profit Report / Today
- Pending Orders -> Orders filtered to Pending
- Return Requests -> Returns filtered to Requested
- Low Stock -> Inventory filtered to Low Stock
- Out of Stock -> Inventory filtered to Out of Stock

Target pages hydrate their filters from URL query parameters so links remain shareable and browser-back friendly.
