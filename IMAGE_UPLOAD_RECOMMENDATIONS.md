# Dashboard image upload recommendations

All dashboard image upload controls now display a visible performance recommendation.

| Upload type | Recommended size | Format | Recommended file size |
| --- | --- | --- | --- |
| Product / variant images | 600 × 600 px | WebP | ≤ 200 KB each |
| Homepage promo banners | 1200 × 600 px | WebP | ≤ 200 KB |
| Homepage editorial banner | 1600 × 800 px | WebP | ≤ 200 KB |
| Website logo | 600 × 180 px | WebP | ≤ 200 KB |
| Dashboard logo | 600 × 180 px | WebP | ≤ 200 KB |

The recommendation is advisory rather than a hard upload limit. When a new image is selected, the dashboard shows the detected dimensions, size and format and warns when the selection differs from the recommendation.
